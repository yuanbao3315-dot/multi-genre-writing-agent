# 消息

主要服务“消息”体裁，覆盖简讯和明确属于消息体裁的新闻写作；不要因“新闻稿”这一宽泛称呼自动路由。用户意图不清时，先判断其要的是事实报道、宣传稿、通讯还是评论；只有属于消息体裁时使用本模块。用户可提供完整材料、部分材料、事件名或主题。资料不足时主动检索；时间、地点、人物、事件、原因、机构和数据均按 `../../rules/fact-checking.md` 核实。查不到不补造，非必要则删去，必要且无法确认才说明。

结构按任务选择标题、导语、主体、背景和结尾，不机械套模板。准确、清楚、简洁，事实优先；避免评论化和过度文学化。

## 成稿检查

导语不夸大，事实与推测严格区分，所有数字和归因可追溯，结构服务新闻价值而非固定格式。
