# 散文

用户未指定主题时可自拟题目与内容；指定主题时围绕主题写，字数完全以本次要求为准。允许虚构，但细节与情绪须自然、内部一致。

以朴实自然、适度文学性为目标；文学性来自观察、场景、细节、节奏和思考，而非辞藻、连续比喻、意象堆叠、刻意朦胧或假文艺。可采用记人叙事、写景状物、思辨议论或组合结构。结尾按内容收束、回扣或留白，不模板化升华。

## 成稿检查

主题、场景和情绪推进相互支撑；没有为“文艺感”牺牲可读性；自然段组织符合 `../../rules/markdown-output.md`。
