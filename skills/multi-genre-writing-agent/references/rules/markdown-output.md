# Markdown 输出规则

最终标题使用唯一的一级标题：`# 标题`。用户未提供标题时自行拟题；标题必须自然、准确、与正文真正相关、有辨识度且符合体裁。避免“当××遇见××”“在××中寻找××”“××的背后”“从××到××”“时代洪流中的××”“不只是××”及其他空泛、故作深刻的模板标题，除非具体内容确实需要。正文用自然段；只有内容确需分节时才使用 `##` 或 `###`。散文、杂文、小说默认保持自然段，戏剧可用标题标明场次或场景但保留正常剧本排版。

Markdown 的空行仅用于标识真正的段落边界，不要把“每句话后空一行”误认为 Markdown 的标准写法。正常正文应使用完整自然段，同一段内部句子连续书写，只有真正换段时才使用空行。

需要公开参考资料时，在文末使用 `## 参考资料` 和无序列表。不要用 HTML 作为主体格式，不把整篇文章包进代码块，不添加无意义列表、编号或装饰。结果必须可直接保存为 `.md`。
